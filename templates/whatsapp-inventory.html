WhatsApp Inventory Intelligence
● ONLINE
How this works. Export a WhatsApp dealer group without media (Chat → Export → Without Media), then separately pick the group's photos/videos/PDFs from your phone. The tool matches them by time, groups messages into properties, and uses AI to build your inventory. Everything stays on your device except the text/images sent to your AI for extraction.
Step 1 · Chat Export

📄 Select chat file

The .txt file from “Export chat → Without media”.

Step 2 · WhatsApp Media

🖼️ Select media files

Pick the photos, videos, PDFs, voice notes for this group. On Android use the file picker — multi-select many at once. You can add more later.

Android blocks any browser from opening WhatsApp's folders automatically — you must pick the files yourself here. Folder-select works on desktop Chrome and some Android builds; if it fails, use Select files.

▶️ Process

⚠️ What this browser tool honestly can't do

Auto-reading WhatsApp's private folders (Android forbids it), processing a whole 50 GB library in one pass on a phone (memory limits — work per group, in batches), and full server-grade video analysis (scene detection / transcription). Video keeps a thumbnail + reference and can be sent to a vision model, but not frame-by-frame processed. These need the native app — ask Bhuvnesh for the build spec.

⚙️ AI (server-powered)

AI runs through the Nisha Homes server using the account's own OpenRouter key — nothing to paste here.

Any multimodal model on OpenRouter works. Cheaper models cost less per property; vision-capable models can read photos & brochures.

Correlation thresholds

How close in time a media file must be to a message to auto-attach.

Privacy

Local: chat, media files, the whole database, all thumbnails — stay in this browser. Sent to AI: only grouped message text and (optionally) matched images, when you press Process. Nothing uploads on its own.
